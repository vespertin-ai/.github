# Security Policy

## Reporting a Vulnerability

Do not open public GitHub issues or pull requests for suspected security vulnerabilities.

Report vulnerabilities through either channel below:

1. **GitHub Private Vulnerability Reporting:** Open a private security advisory on the affected `vespertin-ai` repository.
2. **Security Desk:** Submit a report routed to **Security / Vulnerability Disclosure** at [vespertin.io/#contact](https://vespertin.io/#contact).

Include affected components, reproduction steps, and impact assessment. We acknowledge receipt within 48 hours and coordinate disclosure before public release.
